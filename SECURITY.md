# Security Policy

| Version / Branch | Supported          |
| ---------------- | ------------------ |
| `develop`        | :white_check_mark: |
| `main`           | :white_check_mark: |

---

## Reporting a Vulnerability

If you identify a security vulnerability (such as dataset exposure, credential leaks, or dependency CVEs):

1. **Do not create public GitHub issues or discussions.**
2. Report the vulnerability privately via GitHub Security Advisories:
   * Go to the **Security** tab of [imMohammedSahil/Amazon-ML](https://github.com/imMohammedSahil/Amazon-ML).
   * Click **Report a vulnerability**.
3. Or contact the repository maintainer directly via GitHub [@imMohammedSahil](https://github.com/imMohammedSahil).

### Details to Provide

* Clear description of the vulnerability and attack vector.
* Reproduction steps or proof of concept.
* Any affected files or pipeline stages.
* Potential impacts and remediation suggestions.

### Response Timeline

* **Acknowledgment:** Within 48 hours
* **Remediation & Triage:** Target resolution within 7-14 business days
